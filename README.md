# 上班动力看板 · Little Motivation

按月薪实时算「今天已经赚到多少钱」的小看板。每一秒都在涨，赚够一杯咖啡就点亮一杯咖啡。

纯静态页面，零依赖，数据只存在你自己的浏览器里。

**在线地址：<https://a1ether.github.io/LittleMotivation/>**（手机、公司电脑随时打开）

## 它长什么样

- **今日已赚**：按秒刷新，精确到分以下两位（显示 ¥1,234.56 + 后两位跳动）
- **进度条**：上班到下班的一段，走到 100% 就是自由
- **倒计时**：距开工 / 距下班，下班后变成加班计时
- **四项数字**：距下班、已工作、剩余可得、今日目标，每个数字只出现一次
- **今天的小确幸**：把赚到的钱换算成咖啡、奶茶、午饭、电影票……赚够一件点亮一件（桌面 4×2 对齐，手机 2 列）
- **遮一遮**：一键把金额变成 `•••`（工位上有人凑过来时按 `B`）
- **休息日 / 未开工 / 已下班 / 加班**：都算得对，不会瞎涨

## 使用

打开 `index.html` 即可。或访问 <https://a1ether.github.io/LittleMotivation/>。

首次打开点「设置」填自己的月薪：

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| 月薪 | 税前/税后随你，看你想看哪个数 | 8000 |
| 每月工作日 | 按你实际的月计薪天数填 | 22 |
| 上班 / 下班 | 支持跨夜班（如 22:00–06:00） | 09:00 / 17:00 |
| 下班后继续计薪 | 加班也算钱 | 关 |
| 今天也上班 | 周末/节假日补班时手动开启 | 关 |

算钱方式：`今日已赚 = 月薪 ÷ 每月工作日 ÷ 每班秒数 × 已工作秒数`

快捷键：`S` 设置，`B` 遮一遮。

## 本地运行

不需要构建，任意静态服务器即可（直接双击 `index.html` 也行）：

```bash
python3 -m http.server 8080
```

## 文件结构

```
index.html   页面结构
styles.css   样式（暗色为主，支持浅色 / 跟随系统）
app.js       全部逻辑，约 300 行，无框架无依赖
icon.svg     图标
```

## 说明

- 所有数据存 `localStorage`，不上传任何服务器
- 计时不靠累加，每次都用「当前时间 − 上班时间」重新算，切后台、锁屏、休眠回来都准确
- 仓库内不含任何真实薪资数据
